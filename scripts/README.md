# Scripts

## Core Scripts

- `load_simple.py` - Load data to PostgreSQL
- `run_analysis.py` - Run analysis pipeline
- `expand_us_data.py` - Expand US dataset

## Data Fetching

- `fetch_weather_data.py` - Fetch weather data
- `fetch_transit_data.py` - Fetch transit data
- `process_data.py` - Process and combine data

## Usage

```bash
# Load data
python load_simple.py

# Run analysis
python run_analysis.py

# Expand dataset
python expand_us_data.py
```
